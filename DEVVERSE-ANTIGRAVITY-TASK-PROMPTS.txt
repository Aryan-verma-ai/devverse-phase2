DEVVERSE — ANTIGRAVITY TASK-BY-TASK PROMPT FILE
================================================

HOW TO USE THIS FILE
--------------------
1. Open the existing DevVerse repository in Antigravity.
2. Keep SYSTEM-DESIGN.md and this file available in the project root or provide them as context.
3. Send ONLY ONE numbered prompt at a time. Do not paste the whole file and ask Antigravity to execute everything.
4. Review the checkpoint report and run the app/tests yourself where possible.
5. Approve the task explicitly before sending the next prompt.
6. If a task fails, ask Antigravity to fix ONLY that task, re-run its checks, and report again. Do not skip ahead.
7. Keep a clean Git commit/checkpoint after each approved task or small group of tasks.

GLOBAL RULES — APPLY TO EVERY PROMPT
------------------------------------
- Read SYSTEM-DESIGN.md and the current task before editing.
- Inspect the real repository and relevant files first. Do not assume paths, dependencies, scripts, or behavior.
- Do not rebuild the entire application in one pass.
- Make changes only for the current task. Do not begin future tasks or perform unrelated refactors.
- Preserve DevVerse's identity, current useful artwork, violet/cyan direction, themes, and existing destinations unless the task explicitly changes them.
- Do not remove the Phase 1 source before the new version has been verified. Keep a recoverable baseline.
- Do not claim a test, build, visual check, API call, or database operation passed unless it was actually run and observed.
- Never store plaintext passwords or long-lived auth tokens in localStorage. Never commit secrets.
- No fake success states, random activity, or unlabelled demo metrics.
- Use React declaratively; do not manually mutate DOM elements owned by React.
- Keep code understandable for a college project. Do not add unapproved frameworks or services.
- After the task, report exact changed files, behavior, commands/tests and actual results, manual checks, remaining limitations, and acceptance criteria.
- Finish with: "READY FOR REVIEW — STOPPED. I have not started the next task."
- Wait for the user to approve before proceeding.
